# Skills to upload

If you ask Claude to turn something you do into a skill of your own, for example "make a skill for how we write our ads", it works straight away in Claude Code in this folder. When you want it in Claude itself, so you can use it in every conversation, including the Claude app on your phone, Claude packs it up as a `.zip` file and saves it here.

## How to add it to Claude

1. Open Claude (claude.ai or the Claude app).
2. Go to **Customize**, then **Skills**.
3. Press **+**, then **Create skill**, then **Upload a skill**, and choose the `.zip` file in this folder.

Skills need a paid Claude plan with code execution switched on (in **Settings**, under **Capabilities**).

If the menus look different, ask Claude: "Where do I upload a skill?"
